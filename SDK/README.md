# NovaOryn SDK 0.41.5

NovaOryn SDK 0.41.5 moves interactive shell input ownership into the SDK command-line runtime, services PS/2 input directly and through timer dispatch, and adds Ctrl+A then Ctrl+C shell transcript capture to the NovaOryn IDE Windows clipboard while retaining the stable API/ABI and machine-readable SDK manifest.

## Professional SDK

See `NovaOryn.SdkManifest.json`, `NovaOryn.ApiContract.json`, `docs/Professional-SDK-0.39.0.md`, and `docs/Release-0.41.5.md`.
