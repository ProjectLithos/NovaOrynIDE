NovaOryn.Text.Format

public static String Format(Boolean value) => value ? "True" : "False"

What it does

Returns the normal .NET text for a Boolean value without allocating.

When to use it

Use when you need "True"/"False" text for a Boolean value without allocating, since the hosted-runtime bool.ToString() path is not available in the freestanding environment.

Details

Returns one of two compile-time constant literal strings depending on `value`. Unlike TryFormat, it needs no destination buffer or capacity because the result is never more than one of two fixed strings.

Dependencies

NovaOryn.Freestanding.CoreLib

Return value

The literal string "True" when `value` is true; otherwise the literal string "False".

Example

KernelConsole.WriteLine(StringFormatter.Format(initialized));
