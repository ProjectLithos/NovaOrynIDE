NovaOryn.ProjectModel.TryLoad

public static bool TryLoad(string path, out NovaOrynProject? project, out string error)

What it does

Loads and validates a NovaOryn project manifest (nova.json) from disk.

When to use it

Call from build or launch tooling before you need a project's settings, instead of reading and parsing the manifest JSON yourself.

Details

Reads the file at `path`, deserializes it into a NovaOrynProject, resolves ProjectFile and OutputDirectory to absolute paths relative to the manifest's directory, and then calls Validate on the result. Returns false with a message in `error` if the path is missing, the file cannot be found, the JSON cannot be parsed, or validation fails. Throws ArgumentException only if `path` itself is null or whitespace.

Dependencies

NovaOryn.Core

Return value

true with a non-null `project` if the manifest was found, parsed, and passed validation; false with a populated `error` message and a null `project` otherwise.

Example

if (NovaOrynProject.TryLoad("nova.json", out var project, out var error))
{
    BuildKernel(project!);
}
else
{
    Console.Error.WriteLine(error);
}
