NovaOryn.Kernel.Platform.X64.DisableLegacyPic

public static Boolean DisableLegacyPic() => Native.DisableLegacyPic()

What it does

Disables legacy PIC delivery before APIC routing is configured.

When to use it

Call after the IDT is installed and before configuring the APIC/MSI interrupt controllers, so legacy 8259 interrupts cannot fire once APIC routing takes over.

Details

Masks the legacy 8259 Programmable Interrupt Controller so all subsequent interrupt delivery goes through the APIC/MSI path configured next in the boot sequence.

Dependencies

NovaOryn.Freestanding.CoreLib, NovaOryn.Kernel.X64.LowLevel

Return value

true if the legacy PIC was masked successfully; false otherwise.

Example

if (!KernelPlatform.DisableLegacyPic())
{
    return false;
}
