NovaOryn.Boot.Memory.TryGetUefiDescriptor

public bool TryGetUefiDescriptor(int index, out UefiMemoryDescriptor descriptor)

What it does

Attempts to read one original UEFI descriptor from the retained native buffer.

When to use it

Use for immutable firmware diagnostics before reclaiming or unmapping the buffer.

Details

Documentation pending.

Dependencies

when the index exists and its address is representable.

Example
