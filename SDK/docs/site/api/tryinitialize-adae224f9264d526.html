NovaOryn.Memory.Physical.TryInitialize

public bool TryInitialize(NormalisedMemoryMap map, PhysicalAllocatorWorkspace workspace, int allocationCapacity, int reservationCapacity, out PhysicalMemoryStatus status)

What it does

Initialises the extent manager from immediately allocatable normalised ranges.

When to use it

Call once after memory-map normalisation and before the VMM or kernel heap exists.

Details

Documentation pending.

Dependencies

Caller-owned PhysicalAllocatorWorkspace

Return value

when all free extents and record tables fit the supplied workspace.

Example

bool ready = allocator.TryInitialize(map, workspace, 128, 32, out PhysicalMemoryStatus status);
