NovaOryn.Memory.AddressSpace.Contains

public bool Contains(ulong address) => address >= BaseAddress && address < EndExclusive

What it does

Determines whether one virtual byte lies inside this half-open region.

When to use it

Use when routing an address to the region responsible for it.

Details

Documentation pending.

Dependencies

A validated region.

Return value

when the address is greater than or equal to the base and below the exclusive end.

Example
