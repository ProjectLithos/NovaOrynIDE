NovaOryn.Kernel.Bootstrap · Type

NovaOryn.Kernel.Bootstrap.Kernel

public static unsafe class Kernel

What it does

Defines the authoritative freestanding NovaOryn bootstrap kernel.

When to use it

This type is the root of the boot sequence. It is invoked once by the generated native entry point (NovaOryn.Kernel.Entry.X64) immediately after the UEFI loader hands off control; kernel and driver code does not call into it directly.

Details

Exposes a single method, KMain, which performs the kernel's ordered bring-up: console initialization, UEFI memory map validation, GDT/TSS and IDT installation, legacy PIC disable, ACPI discovery, and the remaining subsystem startup that follows. Each stage is fail-fast: if a stage returns false, KMain stops and returns false immediately rather than continuing into a partially-initialized kernel.
