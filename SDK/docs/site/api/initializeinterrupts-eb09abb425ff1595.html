NovaOryn.Kernel.Platform.X64.InitializeInterrupts

public static Boolean InitializeInterrupts() => Native.InitializeBootstrapInterrupts()

What it does

Installs the bootstrap processor IDT.

When to use it

Call immediately after InitializeDescriptors and before unmasking any interrupt source.

Details

Delegates to the native platform layer to build and load the Interrupt Descriptor Table (IDT) with all 256 vectors for the bootstrap processor.

Dependencies

NovaOryn.Freestanding.CoreLib, NovaOryn.Kernel.X64.LowLevel

Return value

true if the IDT was installed successfully; false otherwise.

Example

if (!KernelPlatform.InitializeInterrupts())
{
    return false; // boot cannot continue without a valid IDT
}
