NovaOryn.Kernel.Platform.X64.Halt

public static Boolean Halt() => Native.Halt()

What it does

Stops the current processor permanently.

When to use it

Call as a terminal action, such as after an unrecoverable boot failure, or when a processor has no further work and should stop consuming cycles.

Details

Issues the native halt sequence for the current processor. On x64 this loops on the hlt instruction and does not return control to the caller under normal circumstances.

Dependencies

NovaOryn.Freestanding.CoreLib, NovaOryn.Kernel.X64.LowLevel

Return value

true if the halt sequence was issued; in practice this call does not return, since the processor stops executing further instructions.

Example

KernelConsole.WriteLine("Fatal error; halting.");
KernelPlatform.Halt();
