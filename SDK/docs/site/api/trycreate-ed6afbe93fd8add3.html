NovaOryn.Memory.Virtual.TryCreate

public static bool TryCreate(ulong start, ulong pageCount, VirtualPageSize pageSize, out VirtualAddressRange range)

What it does

Attempts to create a validated aligned virtual-address range.

When to use it

Use before unmapping or changing protection on a contiguous range.

Details

Documentation pending.

Dependencies

Power-of-two page size and checked address arithmetic

Return value

when the range is non-empty, aligned, and does not overflow.

Example

bool valid = VirtualAddressRange.TryCreate(0xFFFF800000000000, 4, VirtualPageSize.Page4KiB, out VirtualAddressRange range);
