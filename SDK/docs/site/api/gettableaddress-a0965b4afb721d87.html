NovaOryn.Memory.Virtual.X64.GetTableAddress

public static PhysicalAddress GetTableAddress(ulong entry) => new((entry & Present) != 0 ? entry & AddressMask4KiB : 0UL)

What it does

Gets the 4 KiB-aligned physical page-table address stored in a present non-leaf entry.

When to use it

Use while walking intermediate x64 page-table levels.

Details

Documentation pending.

Dependencies

Caller has verified the entry is a present non-leaf pointer

Return value

The physical child-table address, or zero when the entry is not present.

Example

PhysicalAddress child = X64PageTableCodec.GetTableAddress(entry);
