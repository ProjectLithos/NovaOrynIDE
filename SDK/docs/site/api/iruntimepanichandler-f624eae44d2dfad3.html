NovaOryn.Runtime.Contracts.IRuntimePanicHandler

public interface IRuntimePanicHandler

What it does

Defines the contract the compiled runtime calls into when it hits an unrecoverable failure.

When to use it

Implement this to control what happens on a fatal runtime error, for example writing the message to the console or serial port and halting, instead of relying on default runtime behavior.

Details

Panic(message) receives a diagnostic string describing the failure. Because a panic handler will typically halt or reset the processor rather than return control, the bool result mainly communicates whether the message itself was successfully reported before that happens.

Dependencies

NovaOryn.Core, NovaOryn.Primitives

Return value

Not applicable at the type level. Panic returns true if the diagnostic message was successfully reported, false if reporting itself failed.

Example

public sealed class ConsolePanicHandler : IRuntimePanicHandler
{
    public bool Panic(string message) => KernelConsole.WriteLine("PANIC: " + message);
}
