NovaOryn.Kernel.Bootstrap.KMain

public static Boolean KMain(BootContext boot)

What it does

Initializes the kernel platform and enters the interrupt-driven interactive console.

When to use it

Called exactly once, by the generated native entry point, right after UEFI boot services exit and the final memory map is retained. Do not call KMain from driver or application code.

Details

Runs the kernel's subsystem bring-up in a fixed order (console, memory map check, descriptors, interrupts, legacy PIC, ACPI, and onward through the remaining kernel subsystems), writing a status line to the console after each stage. If any stage reports failure, KMain returns false immediately instead of attempting to continue booting.

Return value

true if every boot stage completed successfully and the kernel reached its running state; false if any stage failed, in which case the caller should treat the boot as unrecoverable.

Example

// Generated native entry point calls this once, after ExitBootServices succeeds.
if (!Kernel.KMain(bootContext))
{
    // Boot failed during bring-up; the console will already show which stage failed.
}
