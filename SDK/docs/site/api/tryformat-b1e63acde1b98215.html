NovaOryn.Text.TryFormat

public static unsafe Boolean TryFormat(Int64 value, Char* destination, UInt32 capacity, out UInt32 written)

What it does

Formats a signed 64-bit integer into a caller-owned character buffer.

When to use it

Use for signed values (for example deltas or negative offsets) where the UInt64 overload of TryFormat cannot represent the sign.

Details

Computes the magnitude of `value` using an overflow-safe transform so Int64.MinValue is handled correctly, reserves one extra leading character for '-' when the value is negative, delegates digit formatting to the UInt64 overload, and then writes the sign byte itself.

Dependencies

NovaOryn.Freestanding.CoreLib

Return value

true if the (optionally signed) digits fit within `capacity` and were written to `destination`; false if `destination` was null or too small.

Example

Span<char> buffer = stackalloc char[20];
unsafe
{
    fixed (char* p = buffer)
    {
        bool ok = StringFormatter.TryFormat(-17L, p, 20U, out uint written);
    }
}
