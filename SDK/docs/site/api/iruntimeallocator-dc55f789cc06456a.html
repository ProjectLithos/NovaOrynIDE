NovaOryn.Runtime.Contracts.IRuntimeAllocator

public interface IRuntimeAllocator

What it does

Defines the low-level memory allocation contract the compiled NativeAOT runtime uses for allocation and release inside the freestanding kernel.

When to use it

Implement this interface when wiring a memory backend (typically the kernel heap) into the runtime through RuntimeConfiguration during early boot. Ordinary kernel code should allocate through the higher-level heap APIs rather than this interface directly.

Details

TryAllocate reserves `size` bytes at the requested `alignment` and reports the resulting Address on success. Release returns a previously allocated region of `size` bytes to the allocator. Both members return bool instead of throwing, since exceptions are not available this early in boot.

Dependencies

NovaOryn.Core, NovaOryn.Primitives

Return value

Not applicable at the type level. TryAllocate returns true if the request was satisfied (with `address` set) or false if it could not be; Release returns true if the region was accepted back, false otherwise.

Example

public sealed class HeapAllocator : IRuntimeAllocator
{
    public bool TryAllocate(Bytes size, Alignment alignment, out Address address) => KernelHeap.TryAllocate(size, alignment, out address);
    public bool Release(Address address, Bytes size) => KernelHeap.Release(address, size);
}
