public static bool TryEncodeTablePointer(PhysicalAddress physicalAddress, bool writable, bool userAccessible, out ulong entry)

What it does

Attempts to encode an x64 non-leaf page-table pointer.

When to use it

Use when allocating an intermediate PML4, PDPT, page-directory, or page-table child.

Details

Documentation pending.

when the physical address fits the x64 page-table address field.
