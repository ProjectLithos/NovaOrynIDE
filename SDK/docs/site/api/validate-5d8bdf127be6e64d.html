NovaOryn.ProjectModel.Validate

public bool Validate(out string error)

What it does

Checks that a loaded project manifest is complete and supported by this SDK version.

When to use it

Called automatically by TryLoad. Call it directly only if you construct or modify a NovaOrynProject in memory (for example with a `with` expression) and want to confirm it before using it.

Details

Verifies, in order: Name is non-empty; ProjectFile exists on disk; TargetArchitecture equals "x64" (case-insensitive); BootProtocol equals "Uefi" (case-insensitive); KernelEntry is exactly "KMain". Validation stops at the first failing check.

Dependencies

NovaOryn.Core

Return value

true if every check passes; false with a human-readable description of the first failed check written to `error`.

Example

if (!project.Validate(out var error))
{
    throw new InvalidOperationException(error);
}
