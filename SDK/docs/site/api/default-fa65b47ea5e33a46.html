NovaOryn.Console.Framebuffer.Default

public static FramebufferConfiguration Default(uint fontSize)

What it does

Creates the default framebuffer colours and margin with an exact font size.

When to use it

Use when the kernel wants to choose the actual rendered glyph height without configuring colours individually.

Details

Documentation pending.

Dependencies

NovaOryn Mono embedded raster metrics.

Return value

A framebuffer configuration using the requested font size.

Example

FramebufferConfiguration configuration = FramebufferConfiguration.Default(24U);
