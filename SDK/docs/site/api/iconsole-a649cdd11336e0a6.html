NovaOryn.Console.Contracts.IConsole

public interface IConsole

What it does

Defines the platform-agnostic contract that a console/output backend implements so the kernel can write boot and diagnostic text without depending on a specific device.

When to use it

Implement this interface when adding a new console backend (for example a framebuffer or serial port driver). Application and driver code should not call an IConsole implementation directly; it should go through NovaOryn.Kernel.Console.KernelConsole, which selects and initializes the active backend.

Details

Members: Initialize(BootContext boot) performs one-time backend setup during early boot and reports whether it succeeded; Write(ReadOnlySpan&lt;char&gt;) and WriteLine(ReadOnlySpan&lt;char&gt;) emit text without allocating; WriteLine() emits just a line terminator. Every member returns bool instead of throwing, matching the SDK-wide convention of avoiding exceptions before the managed runtime is fully initialized.

Dependencies

NovaOryn.Boot.Contracts

Return value

Not applicable at the type level. Each member returns bool: true if the operation completed, false if the backend failed or was never initialized.

Example

public sealed class MyFramebufferConsole : IConsole
{
    public bool Initialize(BootContext boot) => TryBindFramebuffer(boot);
    public bool Write(ReadOnlySpan<char> text) => WriteGlyphs(text);
    public bool WriteLine(ReadOnlySpan<char> text) => Write(text) && WriteLine();
    public bool WriteLine() => Write("\n");
}
