NovaOryn.Memory.Heap.TryAllocate

public bool TryAllocate(ulong byteCount, ulong alignment, out ulong address)

What it does

Attempts to allocate aligned bytes monotonically from the caller-owned range.

When to use it

Use for bootstrap-lifetime allocations that need no individual release.

Details

Documentation pending.

Dependencies

A power-of-two alignment and remaining range capacity.

Return value

when the aligned allocation fits.

Example

bool ok = allocator.TryAllocate(128, 16, out ulong address);
