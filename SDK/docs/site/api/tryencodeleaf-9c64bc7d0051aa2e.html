NovaOryn.Memory.Virtual.X64.TryEncodeLeaf

public static bool TryEncodeLeaf(PhysicalAddress physicalAddress, VirtualPageSize pageSize, VirtualMemoryProtection protection, out ulong entry)

What it does

Attempts to encode one x64 present leaf entry for the selected page size.

When to use it

Use after validating processor support for the selected page size and NX policy.

Details

Documentation pending.

Dependencies

Aligned physical address and architecture-neutral protection

Return value

when the address and protection can be represented safely.

Example

bool encoded = X64PageTableCodec.TryEncodeLeaf(new PhysicalAddress(0x200000), VirtualPageSize.Page2MiB, VirtualMemoryProtection.Read | VirtualMemoryProtection.Write, out ulong entry);
