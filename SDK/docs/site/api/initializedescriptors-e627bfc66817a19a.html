NovaOryn.Kernel.Platform.X64.InitializeDescriptors

public static Boolean InitializeDescriptors() => Native.InitializeBootstrapDescriptors()

What it does

Installs the bootstrap processor GDT and TSS.

When to use it

Call once, early in boot, before enabling interrupts, so the processor has valid segment and task-state descriptors.

Details

Delegates to the native platform layer to build and load the Global Descriptor Table (GDT) and Task State Segment (TSS) for the bootstrap processor.

Dependencies

NovaOryn.Freestanding.CoreLib, NovaOryn.Kernel.X64.LowLevel

Return value

true if the GDT and TSS were installed successfully; false otherwise, which should abort the boot sequence.

Example

if (!KernelPlatform.InitializeDescriptors())
{
    return false; // boot cannot continue without a valid GDT/TSS
}
