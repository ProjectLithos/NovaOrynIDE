NovaOryn.Text.TryFormat

public static unsafe Boolean TryFormat(UInt64 value, Char* destination, UInt32 capacity, out UInt32 written)

What it does

Formats an unsigned 64-bit integer into a caller-owned character buffer.

When to use it

Use to render an unsigned integer (sizes, counts, addresses treated as unsigned) into a fixed buffer you already own, without allocating a string.

Details

Writes decimal digits into a 20-character stack scratch buffer in reverse order, then copies them forward into `destination`. Fails immediately if `destination` is null or `capacity` is 0, and also fails if the formatted digit count exceeds `capacity`. `written` is only set on success.

Dependencies

NovaOryn.Freestanding.CoreLib

Return value

true if the digits fit within `capacity` and were written to `destination` (with `written` set to the digit count); false if `destination` was null or too small for the value.

Example

Span<char> buffer = stackalloc char[20];
unsafe
{
    fixed (char* p = buffer)
    {
        bool ok = StringFormatter.TryFormat(1024UL, p, 20U, out uint written);
    }
}
