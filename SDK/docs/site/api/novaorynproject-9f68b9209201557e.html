NovaOryn.ProjectModel.NovaOrynProject

public sealed record NovaOrynProject( string Name, string ProjectFile, string TargetArchitecture, string BootProtocol, string KernelEntry, string RuntimePack, string OutputDirectory)

What it does

Represents a validated, in-memory NovaOryn kernel project manifest: its name, csproj path, target architecture, boot protocol, kernel entry point, runtime pack, and output directory.

When to use it

Obtain an instance with NovaOrynProject.TryLoad when reading a project's nova.json manifest from disk (for example from NovaOryn.VisualStudio, NovaOryn.QemuLauncher, or NovaOryn.ImageBuilder). Construct it directly only when generating a manifest programmatically, such as from NovaOryn.ProjectCreator.

Details

An immutable record with seven required string properties that mirror the on-disk JSON manifest schema. ProjectFile and OutputDirectory are resolved to absolute paths (relative to the manifest's own directory) once the project has been loaded through TryLoad.

Dependencies

NovaOryn.Core

Return value

Not applicable; this is a data record rather than a method.

Example

// nova.json
// { "name": "MyKernel", "projectFile": "MyKernel.csproj", "targetArchitecture": "x64",
//   "bootProtocol": "Uefi", "kernelEntry": "KMain", "runtimePack": "NovaOryn.Freestanding.CoreLib",
//   "outputDirectory": "bin" }
if (NovaOrynProject.TryLoad("nova.json", out var project, out var error))
{
    Console.WriteLine(project!.Name);
}
