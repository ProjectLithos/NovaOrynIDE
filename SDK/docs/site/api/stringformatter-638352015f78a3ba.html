NovaOryn.Text.StringFormatter

public static class StringFormatter

What it does

Provides allocation-free value-to-text helpers for freestanding NovaOryn code.

When to use it

Use anywhere in the kernel or a driver that needs to render a primitive value (bool, or a signed/unsigned integer) as text without heap allocation, such as before writing to the console or a log buffer.

Details

A static class exposing Format(bool), which returns one of two fixed strings, and overloaded TryFormat methods for UInt64 and Int64 that write decimal digits directly into a caller-supplied character buffer instead of returning a new string.

Dependencies

NovaOryn.Freestanding.CoreLib

Return value

Not applicable at the type level; see the individual Format/TryFormat members.

Example

Span<char> buffer = stackalloc char[20];
unsafe
{
    fixed (char* p = buffer)
    {
        if (StringFormatter.TryFormat(42UL, p, 20U, out uint written))
        {
            KernelConsole.WriteLine(buffer[..(int)written]);
        }
    }
}
