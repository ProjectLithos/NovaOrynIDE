NovaOryn.Runtime.Contracts.RuntimeConfiguration

public readonly record struct RuntimeConfiguration( IRuntimeAllocator Allocator, IRuntimePanicHandler PanicHandler)

What it does

Bundles the allocator and panic handler implementations the freestanding runtime is configured with at startup.

When to use it

Construct once during early boot, before any managed allocation occurs, and pass it to the runtime's NativeAOT startup hook.

Details

A readonly record struct with two required members: Allocator (IRuntimeAllocator) and PanicHandler (IRuntimePanicHandler). Both must be supplied; there is no default freestanding implementation of either.

Dependencies

NovaOryn.Core, NovaOryn.Primitives

Return value

Not applicable; this is a data type rather than a method.

Example

var configuration = new RuntimeConfiguration(
    Allocator: new HeapAllocator(),
    PanicHandler: new ConsolePanicHandler());
