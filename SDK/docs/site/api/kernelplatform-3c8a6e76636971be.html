NovaOryn.Kernel.Platform.X64 · Type

NovaOryn.Kernel.Platform.X64.KernelPlatform

public static class KernelPlatform

What it does

Provides high-level x64 processor initialization without exposing native I/O.

When to use it

Called from the kernel bootstrap sequence (see NovaOryn.Kernel.Bootstrap.Kernel.KMain) to bring the bootstrap processor from UEFI hand-off to an interrupt-ready state. Not intended for use once the kernel is running.

Details

A thin static wrapper over the native x64 platform layer, exposing four ordered bring-up steps: InitializeDescriptors, InitializeInterrupts, DisableLegacyPic, and Halt. Callers are expected to invoke them in that order during boot.

Dependencies

NovaOryn.Freestanding.CoreLib, NovaOryn.Kernel.X64.LowLevel

Return value

Not applicable at the type level; see the individual members.

Example

if (!KernelPlatform.InitializeDescriptors()) return false;
if (!KernelPlatform.InitializeInterrupts()) return false;
if (!KernelPlatform.DisableLegacyPic()) return false;
