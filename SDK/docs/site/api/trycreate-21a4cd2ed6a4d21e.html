NovaOryn.Memory.Physical.TryCreate

public static bool TryCreate(nint address, ulong byteLength, out PhysicalAllocatorWorkspace workspace)

What it does

Attempts to describe a non-null writable metadata buffer.

When to use it

Use with static, boot-reserved, stack, or otherwise caller-owned storage before manager initialisation.

Details

Documentation pending.

Dependencies

The caller owns the buffer lifetime

Return value

when the address is non-zero, 8-byte aligned, and the buffer is non-empty.

Example

bool valid = PhysicalAllocatorWorkspace.TryCreate(address, byteLength, out PhysicalAllocatorWorkspace workspace);
