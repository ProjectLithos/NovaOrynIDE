NovaOryn Crash Dump Format 1.0

Magic: NOCD. ABI: 1.0.

NovaOryn crash dumps contain ten versioned sections: CPU state, registers, stack, page tables, processes, modules, heap, memory ranges, panic reason, and driver state.

Compatibility

Major versions are breaking. Minor versions may add optional data. Readers ignore unknown sections and fields. Each section has its own version. NovaOryn IDE 0.10.4 also imports the legacy pre-0.10.4 schemaVersion 1 JSON dumps.

See SDK/docs/Crash-Dump-Format.md in the SDK source for the complete normative format.
