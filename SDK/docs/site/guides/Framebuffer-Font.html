Framebuffer font

NovaOryn framebuffer consoles use the embedded NovaOryn Mono bitmap typeface. It does not require a font file, firmware service, garbage collector or runtime allocation after boot.

Coverage

The embedded raster covers printable ASCII U+0020 through U+007E. Unsupported characters use a visible replacement glyph.

Presets and exact size

The kernel console defines three user-facing presets: 1 = 8 px, 2 = 16 px, and 3 = 24 px. The 0.29.0 kernel source default is 24 px (preset 3). The reusable framebuffer API can also be configured with an exact supported font size through FramebufferConfiguration.FontSize.

Buffering and redraw

Changing a preset redraws retained framebuffer output using the new metrics. Buffering is independent of the font preset and can be set to one, two or three buffers.

Userland command

The bundled font command communicates through NovaOryn Get/Set service 33. Use the command API when a shell or executable loader should expose font selection without linking userland directly to kernel-console internals.
