Formal kernel subsystem contracts

NovaOryn 0.4.0 introduces one stable public boundary for each major kernel subsystem. Cross-subsystem consumers should target NovaOryn.Kernel.SubsystemContracts instead of implementation internals.

Compatibility

Every service reports KernelSubsystemStatus with its subsystem ID, lifecycle state, contract major/minor version and capability bits. Consumers require an exact major version and at least their required minor version. Breaking changes therefore require a new major contract version.

Machine-readable policy

NovaOryn.SubsystemContracts.json is the authoritative mapping from each public boundary to the assembly currently implementing it. The SDK manifest advertises contracts.subsystemContracts independently of the SDK release, API and ABI versions.
