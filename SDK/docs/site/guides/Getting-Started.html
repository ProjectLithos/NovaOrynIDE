Getting Started

Nova Oryn OS SDK builds user-owned freestanding C# operating-system kernels with the repository-pinned .NET NativeAOT toolchain. The SDK keeps architecture, boot, memory, interrupt, device, storage, networking, graphics and user/kernel facilities in reusable assemblies so the generated kernel can remain high-level.

Kernel entry point

[KernelEntry]
public static bool KMain(BootContext boot)
{
    // Initialise only the facilities selected by this OS configuration.
    return CPU.Halt();
}

The public kernel entry is KMain(BootContext). Low-level processor, port-I/O, page-table and device-register work is owned by SDK assemblies rather than being embedded in the user kernel entry file.

Build and run

NovaOryn supports command-line builds and IDE-driven builds. Use the generated build scripts for the project being developed; QEMU execution is a separate run step unless the selected workflow explicitly requests it. In the NovaOryn IDE, the run control can select debug or non-debug execution.

Recommended initialization order

  1. Boot context, console and final firmware memory-map hand-off.
  2. Physical memory, virtual memory and kernel address-space policy.
  3. Early allocator and heap.
  4. ACPI, interrupt controllers, timers and SMP.
  5. Scheduler, protection boundary, system calls and processes.
  6. Driver framework, PCI/PCIe, storage, networking, USB and graphics drivers.
  7. Userland services and shell/GUI components selected by the OS configuration.
