Storage and networking

Block devices and partitions

KernelStorage provides a heap-backed block-device and volume registry. Storage-capable drivers register geometry and read/write/flush callbacks. Partition discovery recognizes MBR and GPT layouts.

VFS and FAT32

The SDK exposes a virtual-filesystem layer for mounted filesystem providers. The bundled FAT32 provider supplies initial read-only FAT32 mounting, 8.3 path lookup, cluster-chain traversal and file reads.

Network stack

KernelNetworking is adapter-neutral and contains Ethernet/ARP/IPv4 services together with ICMP, UDP and TCP facilities. DHCP and DNS helper APIs are also present. VirtIO-net, E1000/E1000e and RTL8168/RTL8111-class adapters integrate with the same network layer.
