Graphics and console

Firmware framebuffer

NovaOryn can register a firmware-provided GOP/VESA-like linear framebuffer as a generic graphics target. CPU writes are already visible to scan-out, so presentation for this target is a validated no-op.

VirtIO GPU

KernelVirtioGpu is NovaOryn's first driver-owned graphics adapter. It implements the modern VirtIO GPU 2D command set, creates scan-out resources, supports mode changes and presents rectangular regions.

Framebuffer buffering

The kernel console supports single, double and triple buffering. Triple buffering uses two software backbuffers plus the firmware scan-out buffer. Userland service 34 exposes presets 1–3.

Font presets

The framebuffer console uses the embedded NovaOryn Mono bitmap typeface. Kernel preset 1 is 8 px, preset 2 is 16 px and preset 3 is 24 px; the current source default is preset 3 / 24 px. The font userland command exposes the same presets through service 33.

Keyboard layouts

The current kernel source loads English_UK and English_USA. The userland keyboard command can query, list and select the installed layout through NovaOryn Get/Set services.

Interactive QEMU console

The bootstrap kernel handles the number keys 1, 2 and 3 as font-preset selectors. The console also retains framebuffer output for redraw and scrollback behavior.
