System calls

NovaOryn supports three syscall methodologies over one protected kernel entry mechanism: the native NovaOryn Get / Set / Event service model, Linux-style syscall compatibility, and Windows/NT-style compatibility.

Native Get / Set / Event model

The native model is intended for discoverable OS services rather than forcing every operation into one global numeric syscall table. SDK code can register Get, Set and Event handlers for userland-facing services.

Compatibility ABIs

The system-call assembly also defines stable Linux-style negative errors and common NTSTATUS values used by the compatibility dispatcher. ABI selection is represented explicitly in the protected syscall frame/capabilities rather than duplicating low-level entry machinery.

Userland service examples

The bundled userland font, buffering and keyboard command assemblies use the NovaOryn service model. Font service 33 controls presets 1–3; buffering service 34 controls one, two or three framebuffer buffers; keyboard exposes the installed English_UK and English_USA layouts.
