USB

NovaOryn 0.29.0 contains a reusable USB bus layer plus xHCI, hub, HID and mass-storage assemblies.

USB bus layer

KernelUsbBus owns host registration, port enumeration, device/interface discovery and the common control, bulk and interrupt transfer contracts.

xHCI

KernelXhci is the PCI xHCI host-controller implementation and provides command, event and endpoint transfer rings. Root-port scanning feeds devices into the common USB bus layer.

Hubs

The hub assembly discovers USB hubs and can enumerate downstream ports through the same bus abstraction rather than hard-coding a one-controller/one-device model.

HID

The HID assembly exposes keyboard events, mouse state, discovery/service operations and boot-keyboard usage translation.

Mass storage

The USB mass-storage assembly integrates discovered USB storage with KernelStorage, allowing it to participate in the same block-device and volume path as other storage drivers.
