Interrupts and timers

NovaOryn separates interrupt dispatch from interrupt delivery. The kernel can expose one driver-facing interrupt contract while the platform selects the best available x64 mechanism.

Interrupt delivery

KernelInterruptBroker owns Local APIC, I/O APIC, x2APIC, MSI and MSI-X delivery. PCI routes prefer MSI-X, then MSI, then I/O APIC INTx when the required facilities are available. Drivers receive opaque handles and diagnostic route information rather than programming those mechanisms directly.

Exception and vector infrastructure

The x64 interrupt assemblies provide the descriptor/entry mechanisms, while interrupt-dispatch and controller assemblies keep handler registration and controller programming separate from ordinary drivers.

Time sources

The time facility includes HPET, TSC/invariant-TSC handling, Local APIC timer support and RTC/CMOS calendar reads. Scheduler preemption can use the calibrated timer path when available.

Polling separation

Polling is kept in a dedicated kernel assembly, with timer dispatch and interrupt dispatch available as separate mechanisms. Device code can therefore migrate from bootstrap polling to timer- or interrupt-driven service without changing the user kernel API.
