Scheduling, protection and processes

SMP and per-CPU state

KernelSmp discovers enabled x64 processors, owns per-CPU bootstrap state and starts xAPIC application processors through INIT/SIPI. It exposes processor counts, online state, bootstrap-processor identity and per-CPU scheduler context storage.

Scheduler

KernelScheduler owns kernel-thread records, per-CPU run state, priority queues, affinity and preemption decisions. It can create threads with page-aligned kernel stacks, change affinity, block/wake/terminate threads, select the next runnable thread and change the scheduling quantum.

User/kernel protection

KernelProtection establishes the x64 ring-0/ring-3 boundary, enables supervisor write protection and available execution protections, validates user mappings, and prevents user mappings from being placed in the kernel half of the address space.

Processes and executables

KernelProcesses creates isolated x64 user processes from validated ELF64 or PE32+ images. Images can be supplied from memory or loaded through the mounted VFS. Each process receives a private lower-half address space and user stack before ring-3 entry.
