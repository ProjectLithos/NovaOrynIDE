Virtual memory

NovaOryn 0.29.0 provides architecture-neutral virtual-memory contracts, checked x64 page-table encoding/decoding and a freestanding manager that attaches to the active CR3 hierarchy.

Supported mappings

The x64 implementation supports 4 KiB, 2 MiB and 1 GiB leaf mappings together with map, unmap, protection replacement, translation, canonical-address validation, page-table allocation and per-page TLB invalidation.

Bootstrap safety

Existing page-table frames are protected from physical reallocation before normal mapping operations are accepted. The kernel address-space layer then applies policy over the lower-level virtual-memory mechanism.

User mappings

User-accessible mappings are validated by the protection layer so ring-3 mappings remain in the canonical lower half and do not silently weaken supervisor-only pages.
