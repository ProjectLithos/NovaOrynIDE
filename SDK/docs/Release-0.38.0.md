# NovaOryn 0.38.0

NovaOryn 0.38.0 establishes the SDK's first stable public API/ABI contract.

- `NovaOryn.SdkManifest.json` is the authoritative machine-readable SDK contract.
- Public API version 1.0 and overall ABI version 1.0 are independent from the SDK release number.
- Kernel, driver, syscall, debugger, crash-dump and heap-diagnostics ABIs are individually versioned.
- Compatibility policy is additive within an API major version; breaking public API changes require a new major API version.
- Documentation compatibility output now records API/ABI versions and a deterministic public API fingerprint.
- Driver manifests generated by NovaOryn IDE declare the API and Driver ABI they target.

Use `Compare-NovaOrynApiCompatibility.ps1` to compare the generated API inventory from a previous release with the current release. Removal or signature change is rejected unless the public API major version changes.
