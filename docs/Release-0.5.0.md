# NovaOryn IDE 0.5.0

NovaOryn IDE 0.5.0 completes driver packaging integration with the embedded NovaOryn SDK. Driver Development Centre projects now have stable package IDs in their schema-v3 `NovaOryn.Driver.json` manifests. The bundled SDK supplies package schema validation, compatibility checks, `.nodrv` packaging, signing metadata fields, and package-aware Visual Studio driver templates.
