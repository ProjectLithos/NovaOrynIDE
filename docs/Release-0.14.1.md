# NovaOryn IDE 0.14.1

0.14.1 corrects the Engineering-layout release verifier introduced in 0.14.0.

Engineering tools still open in the main document area by default, but this is only a first-open default. The verifier no longer treats the user's later docking choice as a fixed product layout. Users may move Engineering documents to another tab group, side area, or bottom area and allow Theia to persist that layout normally.

The 0.14.0 hardware-abstraction boundary remains unchanged.
