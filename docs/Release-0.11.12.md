# NovaOryn IDE 0.11.12

NovaOryn IDE 0.11.12 adds the NovaOryn logo to the repository README and adds three comprehensive operating-system creation presets to the IDE start page: Full Kernel, Microkernel, and Monolithic Kernel.

Each preset enables the complete mutually compatible NovaOryn SDK surface for x86-64, routes generation through the authoritative configurator, and generates a `PUBLIC-SDK-USAGE.md` guide pointing to the live Boot/HAL code paths that exercise the public SDK contracts.
