# NovaOryn IDE 0.3.0

## SDK API documentation

- Adds **Help → SDK API** to the IDE main menu.
- Opens the SDK API documentation inside a dedicated IDE editor-area tab.
- Uses the API site bundled with the IDE under `SDK/docs/site/index.html`, so the documentation is available offline and remains matched to the bundled SDK.
- Relative links, guides, API pages, search assets, styles and scripts continue to resolve from the bundled site.

## Version

NovaOryn IDE is now version **0.3.0**.
